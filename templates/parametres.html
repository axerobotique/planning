Paramètres — Codes & couleurs

← Retour au planning

Ces codes (ex : ROB, CAB, MES…) servent de préfixe au début du texte d'une tâche ("CODE - Client") pour lui donner sa couleur dans le planning. Change le libellé ou la couleur directement dans le tableau — c'est enregistré immédiatement. L'identifiant du code lui-même n'est pas modifiable une fois créé (ça casserait la reconnaissance des tâches déjà écrites avec ce code) : pour le renommer, crée le nouveau code puis supprime l'ancien.
